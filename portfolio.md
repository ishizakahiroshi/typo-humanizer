## ja

SKILL.md を読んだ AI エージェントが、指定した入力方法や強さに応じて文章へ小さな入力ミスを足します。言い回しや口調を書き換えるものではありません。言語ごとの pack を持ち、数字・日付・URL・コード・固有名詞などの保護対象を定義しています。単体アプリではなく Markdown の skill で、AI 判定ツールの回避を保証するものではありません。公開例は合成データです。

## en

An AI agent reads SKILL.md and adds small input mistakes according to the requested input mode and intensity. It does not rewrite wording or tone. Language packs define slip patterns while numbers, dates, URLs, code and names are protected. This is a Markdown skill rather than a standalone app, and it makes no promise about bypassing AI detectors. Public examples use synthetic data.
